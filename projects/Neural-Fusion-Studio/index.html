Neural Fusion Studio

The Neural Fusion Studio App is a JavaFX-based application with integrated CSS for styling. This project aims to provide a comprehensive and user-friendly interface for neural network fusion and processing. similar to WEKA but with some different features and a more modern styling and better ui/ux here is a link to an explinatory video : https://youtu.be/D2U_S81dT4o

Technology Stack...

  • JavaFx JavaFX is a Java library for building modern, cross-platform GUI applications with rich media and UI components.
  • CSS CSS is a style sheet language used for describing the presentation of a document written in a markup language like HTML.
  • FXML FXML is an XML-based language that provides the structure for building a user interface separate from the application logic.
  • RMI RMI (Remote Method Invocation) is a Java API that performs the object-oriented equivalent of remote procedure calls (RPC).
  • Deep Learning Deep Learning is a subset of machine learning in artificial intelligence (AI) that has networks capable of learning unsupervised from data that is unstructured or unlabeled.
